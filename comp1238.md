## Week 2 - How Text and Numbers are Represented in Computers
- A binary digit known as bit has two states e.g. off and on, true and false, 0 and 1
- 8 bits grouped together is knows as a byte, it became the universal convention
- Historically there existed punch cards which could store 80 bytes of information
- Modern SD cards can store huge amounts 8 gigabytes, 16GB etc
- Computer systems store two types of memory short term volatile memory (RAM) and long term non-volatile memory
- (HDDs, SSDs)
- Hard disks drives consist of spinning magnetic disks, slower due to mechanical movement
- Solid state drives use semiconductor chips and store date electronically, they are faster and more expensive than HDDs
- Kilobyte (KB): ~ thousand bytes
- Megabyte (MB): ~ million bytes
- Gigabyte (GB): ~ billion bytes
- Terabyte (TB): ~ trillion bytes
- KB can be 1000 bytes or 1024 bytes, storage manufactures use 1000 while operating systems and software use 1024
- Least Significant Bit (LSB) for the rightmost bit (representing the smallest power of 2) and Most Significant Bit (MSB) for the leftmost bit (representing the largest power of 2
- Signed numbers represent negative numbers and make one bit show the sign
- 8-bit signed integer, represent numbers from -128 to +127
- floating-point representation, allows computers to represent a wide range of numbers, both very large and very small, including those with fractional parts
- ASCII table (American Standard Code for Information Interchange). Developed in the early 1960s
- ASCII assigned numbers from 0 to 127 to common English letters (uppercase and lowercase), digits (0-9), punctuation marks, and control characters.
- Text files are human readable, binary files are not (JPEG, PNG, ziP, etc)
